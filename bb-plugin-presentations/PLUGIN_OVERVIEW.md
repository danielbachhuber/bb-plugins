Give a talk from a bb thread, with the agent that writes the slides one click
away.

## What you get

- A **Presentations** page that starts a presentation thread with bb's own
  composer. You name a folder; the agent writes one markdown file per slide
  in it, numbered in the order they are shown.
- A **Present** button in that thread's header, which opens the slides in a
  panel beside the chat. The panel lists every slide file, and the pencil on
  each opens it for editing.
- **Full screen** in the panel, and **New window** for a browser window you
  can move to a projector. Arrow keys, Page Up and Page Down, and a
  presentation clicker all move between slides.
- Slides reload within about two seconds of an edit, by you or the agent.

## How it works

The slides stay where the agent wrote them, in the thread's workspace or any
folder on the machine. The plugin stores only which folder belongs to which
thread. Nothing leaves the machine, and it needs no account or external
service.
